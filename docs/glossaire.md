|Num | Termes                     | Définitions                                                                                                                                                    |
| -- | -------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1 | Vague                      | Périodes de vente à prix fixe, close à sa date ou quand son quota est épuisé.                                                                              |
| 2 | Vague Early                | Periode de vente qui débute tôt à prix fixe, généralement moins cher.                                                                                     |
| 3 | Vague Regular              | Periode de vente qui débute après la Vague Early à prix fixe.                                                                                               |
| 4 | Vague Last Minute          | Periode de vente qui débute tard à prix fixe, généralement plus cher.                                                                                       |
| 5 | Festivalier                | Personne ayant payé son entrée pour participer sur une ou plusieurs journée de festival.                                                                     |
| 6 | Organisateur               | Personne désigné pour faire la gestion et l'organisation d'une journée pour proposer un festival. Il assure également les ventes                            |
| 7 | Pass                       | Element confirmant l'achat d'une place pour le festival, peut être pour un jour précis ou pour 3 jours                                                     |
| 8 | Bracelet                   | Il est donné après validation du pass a l'entrée du festival, il permet d'effetuer des payement dans le festival                                             |
| 9 | Bénévoles                | Ensemble de personnes qui agissent bénévolement avec le festival pour aider l'organisation.                                                                   |
| 10 | RFID                       | Radio-Identification. Elle est utilisé pour faire gestion de porte monnaie sur le bracelet.                                                                    |
| 11 | PSP                        | Prestataire de service de paiement                                                                                                                              |
| 12 | Pivot                      | Etape importante qui marque un changement entre 2 étapes ( Tel que ; ouverture de la boutique, Confiramtion de commande, echange billet contre bracelet .. ) |
| 13 | VIP                        | 'Very Important Person'. C'est un festivalier qui paye plus pour accéder à des services supplémentaires.                                                                      |
| 14 | Commande                   | Action d'achat d'un pass                                                                                                        |
| 15 | Concert                    | Animation musicale                                                                                                                                              |
| 16 | Festival                   | Ensemble de concert, sur plusieurs jours                                                                                                                                     |
| 17| Tête d'affiche            | Groupe le plus important de la journée qui attire la plupart des festivalier                                                                                   |
| 18 | Cashless                   | Matériels de paiement qui permettent d’utiliser un support comme porte-monnaie                                                                               |
| 19 | Comission                  | Pourcentage des revenus qui vont vers les prestataires.                                                                                                         |
| 20 | API                        | Interface Logicielle permettant d'accéder à un logiciel ou service.                                                                                           |
| 21 | Quota                      | Le nombre maximum de billets vendus dans une vague.                                                                                                             |
| 22 | Recharge                   | Ajouter de l'argent sur le solde cashless                                                                                                                       |
| 23 | Revente                    | Revendre son billet                                                                                                                                             |
| 24 | Groupe                     | Ensemble de musiciens jouant sur le festival.                                                                                                                   |
| 25 | Remboursement              | Le retour du solde cashless                                                                                                                                     |
| 26 | Contrôle d'accès ou scan | La vérification du billet à l'entrée.                                                                                                                        |
